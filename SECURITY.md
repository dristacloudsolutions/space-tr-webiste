# Security Policy

This website is built and maintained by Drista Cloud Solutions LLP.

## Supported versions

Only the version currently deployed from the `main` branch is supported. Fixes are made on `main` and deployed from there.

## Reporting a vulnerability

Please report security issues privately. Do not open a public issue or pull request about them.

- **Preferred:** use **Report a vulnerability** on this repository's **Security** tab (GitHub private vulnerability reporting).
- **Or email:** contact@drista.in, with "Security" in the subject.

Please include:

- what the issue is and where (page, URL or file)
- steps to reproduce it, or a proof of concept
- the impact you think it has

## What happens next

- We aim to acknowledge your report within 3 working days.
- We will look into it, keep you updated, and tell you when it is fixed.
- We ask that you give us reasonable time to fix the issue before sharing it publicly.

Please test only against your own accounts and data. Do not access, change or delete other people's data, disrupt the service, or run automated scans that put load on it.

## Out of scope

- Reports from automated scanners without a demonstrated impact
- Missing security headers or best practices with no demonstrated way to exploit them
- Social engineering, physical attacks, or attacks on third-party services this site uses (for example its hosting provider)
